    # 🚀 MATsHub - Digital Solutions & Learning Platform

Welcome to **MATsHub**, a modern, responsive, and interactive website designed to showcase digital services, professional courses, and innovative business solutions.

Built with a clean UI, smooth animations, and full Light/Dark mode support, this project demonstrates modern frontend development practices using HTML, Tailwind CSS, and JavaScript.

---

## 🌟 Features

- 🎨 Modern & Responsive UI
- 🌙 Light / Dark Mode
- ⚡ Smooth Animations & Hover Effects
- 📱 Mobile Friendly Design
- 🎓 Professional Course Section
- 💼 Digital Services Showcase
- 📊 Interactive Dashboard Hero
- 🎯 Call-To-Action Sections
- 🔥 Animated Background Effects
- 👨‍💻 Floating Founder Profile Widget
- 🚀 Optimized Performance
- 💻 Cross Browser Compatible
